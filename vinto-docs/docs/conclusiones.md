# Conclusiones

* La separación en páginas, componentes, modelo y servicio facilita mantener y ampliar el sistema.
* SQLModel con SQLite permite guardar los reportes sin instalar un servidor de base de datos.
* El archivo `.env` separa la configuración del código.
* MkDocs con Material permite publicar documentación clara y profesional a partir de archivos Markdown.

## Mejoras futuras

* Autenticación de usuarios.
* Estados de seguimiento del reporte (pendiente, en revisión, resuelto).
* Filtros por tipo de incidente y por fecha.
* Despliegue en un servidor para uso real del municipio.
